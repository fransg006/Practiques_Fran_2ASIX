Per a que canvie el lloc web, he fet estes modificacions al CSS anomenat.

Ara el lloc web, després de fer eixos canvis i haver-lo recarregat, es veu així.

Part 2 - Personalitzar el fitxer theme.json

  • Ubica i edita el fitxer json

Afegeix una nova paleta de colors personalitzada dins del bloc "settings"

El fitxer json es troba dins del directori del tema sel·leccionat, a la ruta que es veu a la seguent imatge, amb els canvis que es veuen a continuació.

CAPTURA de l'ubicació del json i els canvis fets.

Després de guardar els canvis realitzats, accedim dins de l'editor de WordPress, en Aparença>Editor i es pot veure la nova paleta de colors.
